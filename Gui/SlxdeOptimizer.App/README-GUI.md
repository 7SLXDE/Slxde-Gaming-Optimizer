# SLXDE'S OPTI GUI Preview

Version: v0.9.65 Debloat Polish

## What this is

This is the first WPF button-app shell for Slxde Gaming Optimizer.

It includes:
- dark purple / galaxy-inspired interface
- sidebar navigation
- glowing tweak cards
- Apply buttons
- admin status message
- early PowerShell runner
- several buttons already wired to existing `.ps1` module functions

## How to open

Open this file in Visual Studio:

`Gui\SlxdeOptimizer.App\SlxdeOptimizer.App.csproj`

Then press:

`Ctrl + F5`

or click:

`Start Without Debugging`

## Notes

This is a preview shell, not the final app.

Some buttons are layout-only and show PREVIEW.
More buttons will be connected in v 0.9.65+.
